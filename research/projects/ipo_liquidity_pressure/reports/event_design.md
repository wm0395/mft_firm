# IPO Event And Basket Design

## Event Timeline

| Event | Use |
| --- | --- |
| rumor or media buzz | earliest attention proxy |
| DRHP filing | formal intent signal |
| RHP / price band announcement | stronger planning signal |
| anchor book date | institutional activity marker |
| IPO open date | blocking begins |
| IPO close date | application window ends |
| allotment date | funds debit or release |
| refund / unblocking date | deployable liquidity returns |
| listing date | attention and capital may rotate again |

## Event Windows

- Pre-preparation: price-band or RHP attention through the day before IPO open.
- Application: IPO open through IPO close.
- Blocking: IPO close + 1 through allotment - 1.
- Release 1: allotment through allotment + 3 trading days.
- Release 2: allotment through allotment + 5 trading days.
- Listing: listing through listing + 5 trading days.
- Long reversal: allotment through allotment + 20 trading days.

## Basket Types

- Broad market.
- Retail-sensitive smallcap and midcap proxies.
- Recent winners used as cash sources.
- Liquid, easy-to-sell names.
- Same-sector listed competitors or substitutes.

## Pressure Buckets

- Low pressure.
- Medium pressure.
- High pressure.
- Extreme pressure.

## Regime Split

- Pre T+3 listing regime.
- Post T+3 listing regime.

## Intended Use

The event design should let the research separate liquidity pull, blocking, and
release effects without assuming the same baskets participate in every phase.

- Mainboard IPOs first; SME IPOs remain excluded in the first pass.
