# Multi-Asset Expansion

This project tracks the first deterministic expansion beyond the current
Alpha101 exact-OHLCV lane.

Scope:

- Indian equities
- Indian ETFs
- NSE indices
- NSE equity derivatives
- MCX commodities
- macro series
- FX proxies
- global ETF proxies

The queue files define the first executable research work. The config files
define conservative source priority and universe assumptions. No source is
treated as production-ready without ingestion, quality checks, and reviewed
artifacts.
